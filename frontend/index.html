Pipeline

How RepoLens Works

From raw source code upload to instant AI answers: witness the complete codebase ingestion workflow.

1

Repository Upload

Upload your source codebase package securely via multipart ZIP upload.

2

Filtering

The scanner filters lockfiles, build artifacts, node_modules, and media assets to parse only source files.

3

Analysis

Tree-sitter structures code syntax and extracts metadata about files, imports, classes, and dependencies.

4

Embeddings

Code chunks are transformed into dense vectors and stored securely in the database vector index.

5

Semantic Retrieval

When you ask a question, the engine retrieves matching code contexts using cosine similarity thresholds.

6

Gemini AI

Relevant code contexts are injected into a structured context window and passed to the Gemini LLM.

7

Answer

Get a detailed, contextualized answer explaining exactly how the code implements the target feature.
